# 📌 Deskripsi Project

Project ini merupakan implementasi Big Data Technology menggunakan:

- Apache Spark (PySpark)
- Machine Learning
- Parquet Storage
- Dashboard Streamlit

Sistem digunakan untuk melakukan analisis dan prediksi jumlah pengunjung retail berdasarkan zona dan waktu kunjungan.
